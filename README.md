# Eksperimen SML Felda-Ega

Repository ini berisi eksperimen data untuk dataset Breast Cancer.

## Dataset
Breast Cancer Wisconsin Diagnostic. Klasifikasi biner.

## Cara Menjalankan Notebook
1. `pip install -r requirements.txt`
2. `jupyter notebook preprocessing/Eksperimen_Nama-Siswa.ipynb`

## Cara Menjalankan Automasi Preprocessing
1. `cd preprocessing`
2. `python automate_Nama-Siswa.py`

Output: `breast_cancer_preprocessing.csv`

## GitHub Actions
Workflow CI `preprocessing.yml` akan berjalan otomatis saat push ke branch main, atau via workflow_dispatch.
